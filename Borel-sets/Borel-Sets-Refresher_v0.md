# Borel sets — a refresher

## The definition

For a topological space $X$, the **Borel $\sigma$-algebra** $\mathcal{B}(X)$ is the *smallest* $\sigma$-algebra containing all open sets:

$$\mathcal{B}(X) = \bigcap \{\Sigma : \Sigma \text{ is a } \sigma\text{-algebra on } X,\ \tau_X \subseteq \Sigma\}$$

(the intersection of $\sigma$-algebras is again a $\sigma$-algebra, so this exists). Sets in it are **Borel sets**.

Two points worth internalizing:

- **Many equivalent generators.** On $\mathbb{R}$ (or any second-countable space), $\mathcal{B}(\mathbb{R})$ is equally well generated by: open sets, closed sets, compact sets, open intervals, half-lines $(-\infty, a]$, closed boxes. This is a standard $\pi$-system/Dynkin-lemma argument. So "Borel" doesn't depend on which family of nice sets you start from.
- **Minimality is the point.** $\mathcal{B}(X)$ is the smallest $\sigma$-algebra making *every continuous function measurable*: if $f: X \to Y$ is continuous, $f^{-1}(U)$ is open, hence Borel. It's the default because analysis happens on topological spaces and uses continuous functions.

## What's in it

By construction: complements, **countable** unions, countable intersections of Borel sets are Borel. That's it — uncountable operations are not allowed, and this is where everything breaks.

- $\mathbb{Q} = \bigcup_{q \in \mathbb{Q}} \{q\}$ is Borel (each singleton is closed) — class **$F_\sigma$**.
- $\mathbb{R} \setminus \mathbb{Q}$ is Borel — class **$G_\delta$**.
- The Cantor set is closed (hence Borel), uncountable (cardinality $\mathfrak{c}$), and Lebesgue measure zero.
- A Vitali set is an uncountable union of Borel singletons and is **not** Borel — the first warning that countability in the definition is load-bearing.

## The Borel hierarchy

Iterate countable unions/complements starting from open sets:

| Class | Name | Description | Example |
|---|---|---|---|
| $\Sigma^1_0$ | open | — | $(0,1)$ |
| $\Pi^1_0$ | closed | — | $[0,1]$ |
| $\Sigma^1_1$ | $F_\sigma$ | countable $\bigcup$ of closed | $\mathbb{Q}$ |
| $\Pi^1_1$ | $G_\delta$ | countable $\bigcap$ of open | $\mathbb{R}\setminus\mathbb{Q}$ |
| $\Sigma^1_2$ | $G_{\delta\sigma}$ | countable $\bigcup$ of $G_\delta$ | — |
| $\Pi^1_2$ | $F_{\sigma\delta}$ | countable $\bigcap$ of $F_\sigma$ | — |
| … | | continue transfinitely up to $\omega_1$ | |

Every Borel set of $\mathbb{R}$ appears at some level $< \omega_1$. Two facts:

1. **In metric spaces the first level collapses:** every closed set is $G_\delta$ ($F = \bigcap_n \{x: d(x,F) < 1/n\}$) and every open set is $F_\sigma$ ($U = \bigcup_n \{x: d(x, X\setminus U) \ge 1/n\}$). The hierarchy genuinely starts moving at level 1.
2. **The hierarchy is strict** (up to $\omega_1$, on any uncountable Polish space), and Baire category is the clean proof: $\mathbb{Q}$ is $F_\sigma$ but not $G_\delta$ — a dense $G_\delta$ in a complete metric space is comeager, while $\mathbb{Q}$ is meager. Dually, the irrationals are $G_\delta$ but not $F_\sigma$.

Historical anchor (and a nice test of the machinery): Borel's 1895 result that the set of convergence of a power series $\sum a_n x^n$ is Borel. Writing the Cauchy criterion $\forall k\ \exists N\ \forall m,n \ge N: |S_m(x) - S_n(x)| < 1/k$ in open sets gives a set of class $\Sigma^1_2$ — one of the first deep uses of the hierarchy.

## How many Borel sets are there?

On any second-countable space (so $\mathbb{R}$, $\mathbb{R}^d$, any separable metric space), $|\mathcal{B}(X)| = \mathfrak{c}$: every Borel set is built from a countable base by countable operations, and there are only $\mathfrak{c}$ such "Borel codes" (well-founded trees on a countable set). But $|\mathcal{P}(\mathbb{R})| = 2^{\mathfrak{c}} > \mathfrak{c}$.

Consequences:
- **Almost all subsets of $\mathbb{R}$ are not Borel.**
- Every set of cardinality $\le \aleph_0$ is Borel (it's $F_\sigma$).
- There are uncountable non-Borel sets (Vitali, Bernstein sets), all of cardinality $\mathfrak{c}$.

## Borel vs. Lebesgue

The Lebesgue $\sigma$-algebra is the **completion** of $\mathcal{B}(\mathbb{R})$ w.r.t. Lebesgue measure:

$$\mathcal{L} = \{ B \cup N : B \in \mathcal{B}(\mathbb{R}),\ N \subseteq M \text{ for some Borel null set } M\}$$

- Borel $\Rightarrow$ Lebesgue measurable; the converse fails. The Cantor set $C$ is Borel and null; it has $2^{\mathfrak{c}}$ subsets, all Lebesgue measurable (measure 0), but only $\mathfrak{c}$ Borel. So most subsets of $C$ are Lebesgue-measurable non-Borel.
- In $L^p$-theory the distinction is invisible (you work with equivalence classes mod null sets); it matters for pointwise-defined objects: versions of random variables, pointwise limits of measurable functions, etc.

## Why this is "the" $\sigma$-algebra

1. **Maximality under countable additivity.** No strictly larger $\sigma$-algebra than $\mathcal{B}(\mathbb{R})$ supports a translation-invariant, countably additive, normalized measure (Vitali's argument). So the Borel algebra (or its completion) is the largest sensible domain of the Lebesgue integral on $\mathbb{R}$.
2. **Regularity.** Every Borel probability measure on a metric space is regular: outer regular by open sets, inner regular by compact sets.
3. **Riesz–Markov–Kakutani.** Positive linear functionals on $C_c(X)$ $\leftrightarrow$ Radon (Borel) measures. This is the bridge between "integrating against a measure" and "functionals on test functions" — a distribution is a continuous linear functional on test functions; a measure is a positive one.
4. **Bochner.** A continuous positive-definite function on $\mathbb{R}^d$ is the Fourier transform of a unique finite positive Borel measure — the characteristic function determines the distribution.
5. **Uniqueness by a determining class.** A probability measure on $(\mathbb{R}, \mathcal{B})$ is determined by its values on the half-lines $(-\infty, a]$ (Dynkin's $\pi$-$\lambda$ lemma) — which is exactly why a CDF determines a law.

## Standard Borel spaces

The Borel $\sigma$-algebra of a **Polish** space (separable + completely metrizable) is a *standard Borel space*. Two theorems make this the default universe of probability and analysis:

- **Borel isomorphism theorem:** any two uncountable standard Borel spaces are Borel-isomorphic (a bijection measurable in both directions). So as far as Borel structure goes, $\mathbb{R}$, $\mathbb{R}^d$, $[0,1]$, Cantor space $\{0,1\}^{\mathbb{N}}$, $C[0,1]$, $L^p[0,1]$ ($p<\infty$) are all "the same space."
- **Measure isomorphism theorem:** any two atomless standard Borel probability spaces are measure-isomorphic. This is why all "continuous" random variables live in the same world, and why you can model any atomless law as a map into $([0,1], \lambda)$.

## Where it shows up in physics

1. **Random variables.** $X: (\Omega, \mathcal{F}, P) \to (\mathbb{R}, \mathcal{B}(\mathbb{R}))$ is a random variable *iff* $X^{-1}(B) \in \mathcal{F}$ for every Borel $B$. The law $P \circ X^{-1}$ is a Borel probability measure on $\mathbb{R}$, determined by the CDF. This is the single most common place the word "Borel" meets a physicist.
2. **Spectral theorem (QM).** For a self-adjoint $A$ with spectrum $\sigma(A)$, there is a unique projection-valued measure $E: \mathcal{B}(\sigma(A)) \to \mathcal{P}(\mathcal{H})$ (countably additive in the strong operator topology) with $A = \int_{\sigma(A)} \lambda\, dE(\lambda)$. For each state $\psi$, $\mu_\psi(B) = \langle \psi, E(B)\psi\rangle$ is a Borel measure, and the **Borel functional calculus** gives $f(A) = \int f\, dE(\lambda)$ for Borel-measurable $f$. Here "Borel" is not decoration — the domain of the PVM *is* the Borel $\sigma$-algebra of the spectrum.
3. **Path integrals / Wiener measure.** The rigorous (Wick-rotated) path integral is the Wiener measure on $C[0,1]$: a Borel probability measure on a Polish space with $\mathbb{E}[x_s x_t] = \min(s,t)$. The cylinder $\sigma$-algebra (finite time evaluations) generates the full Borel $\sigma$-algebra — this is the countable-product regime where the two coincide. Feynman–Kac then recovers the kernel of $e^{-tH}$.
4. **Euclidean QFT (Osterwalder–Schrader).** A Schwinger function satisfying the axioms reconstructs a measure on $\mathcal{S}'(\mathbb{R}^d)$ — again a Borel measure on a Polish space.
5. **Statistical mechanics.** Gibbs measures on configuration space $S^{\mathbb{Z}^d}$ (Cantor space, compact metric) are Borel probability measures satisfying the DLR equations; the DLR equations fix the measure on cylinder sets, a determining class.
6. **Ergodic theory / statistical physics.** Measure-preserving transformations on standard Borel probability spaces; Birkhoff's ergodic theorem for $L^1$ observables; ergodicity = no nontrivial invariant Borel sets.
7. **Weak convergence of measures** (everywhere in PDE and analysis): Prokhorov — on a Polish space, tightness $\Leftrightarrow$ relative compactness in the weak topology; Portmanteau — $\mu_n \to \mu$ weakly iff $\int f\, d\mu_n \to \int f\, d\mu$ for bounded continuous $f$, equivalently $\mu_n(C) \to \mu(C)$ for every *continuity set* $C$ (a Borel set whose boundary has $\mu$-measure zero).

## Pitfalls

- **Uncountable unions of Borel sets need not be Borel** — a Vitali set is an uncountable union of Borel singletons.
- **"Described" $\neq$ Borel.** Only countable operations are licensed. Definitions involving uncountable quantification over sets, or a choice (Vitali), typically land outside $\mathcal{B}(\mathbb{R})$.
- **Products.** For *countable* products of second-countable spaces, $\mathcal{B}(X^{\mathbb{N}})$ = the cylinder $\sigma$-algebra. For *uncountable* products, the cylinder $\sigma$-algebra is strictly smaller than the Borel $\sigma$-algebra of the product topology — this is the technical crux of formal measures on infinite-dimensional spaces (path integrals).
- **Second countability is doing work.** On an uncountable discrete space, Borel = the full power set. The "$\mathfrak{c}$ many Borel sets" fact is a feature of second-countable spaces.
- **Borel vs. Lebesgue** differ only by null sets on $\mathbb{R}^d$, but "Lebesgue measurable" is the right word for the domain of the Lebesgue integral; "Borel" is the topological notion.

## Where the story continues

Above the Borel sets lies descriptive set theory: **analytic sets** (continuous images of Borel sets, equivalently projections of Borel sets in $\mathbb{R}^2$) are always universally measurable but not all Borel; then coanalytic sets and the projective hierarchy. The Borel sets are exactly the class closed under the countable operations that analysis actually uses — which is precisely why they, and not anything bigger, are the natural home of Lebesgue integration, probability laws, and spectral measures.
